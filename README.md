# LightControlledCar

An Arduino car programmed in C++ that uses two photoresistors to sense the direction of a light and drives away from it.

<img width="1600" height="1200" alt="robot-car-1" src="https://github.com/user-attachments/assets/b459ccb2-edf2-402a-b82f-8225b0db7963" />

I designed custom mounts for the Arduino, breadboard and wiring harness in SolidWorks.
